# Result page comprehension study

Research use only. For evaluation and education. Clinical decisions require laboratory confirmation.

## Study question

Can intended readers identify the recorded referral reason and distinguish the catalogue call, the model estimate, the recorded lab result, and the archived carrier counts?

## Materials and procedure

Use the public replay archive. Select an unresolved case with evidence from both study sources, an example with no carriers in one source, and a case with several reported variants. Use comparable cases across the previous and revised page layouts. Keep the page labels and assay context visible. Alternate the order of layouts and rotate the cases to reduce learning effects.

Ask people who review laboratory or research reports to complete the tasks without coaching. Use the same prompts and answer key for each layout. Ask participants to explain their answers in their own words before discussing the study with them.

| Ask the reviewer | Count the response as correct when |
| --- | --- |
| What did Discern report and why was the case referred? | The reviewer identifies the catalogue call and recognizes when the detailed reason was absent from the archive. |
| Which value came from the laboratory? | The reviewer points to the recorded lab result and distinguishes it from the model estimate. |
| What do the two counts mean? | The reviewer interprets each numerator and denominator as observations from that study source. |
| What does an empty cohort count establish? | The reviewer recognizes that there are no recorded carriers in the source and that this leaves the outcome unknown for that source. |
| Can the file establish whether the changes share a genome? | The reviewer identifies that bulk read fractions do not establish this. |

## Analysis

Record correct and incorrect responses by task and layout, missing responses, and recurring misunderstandings. Report paired differences alongside the number of participants and examples of interpretation errors. Keep any usability claim tied to reviewer performance on those tasks. Use anonymous response codes and retain no private patient data.

## Status

This is a study protocol. Reviewer responses and outcomes have yet to be collected. The archived evaluation reports cover model behavior, and automated page tests cover rendering and data presentation.
